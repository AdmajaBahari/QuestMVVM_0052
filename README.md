# QuestMVVM_0052

Aplikasi Android sederhana dengan arsitektur MVVM menggunakan Jetpack Compose
dan Navigation Compose.

- Nama: Admaja Bahari
- NIM: 20230140052

## Fitur
- Form pendaftaran siswa (nama, jenis kelamin, alamat)
- Navigasi dari halaman Form ke halaman Detail membawa data
- Data disimpan di ViewModel menggunakan StateFlow

## Struktur Project
- `model` : Siswa, DataJK
- `view` : FormSiswa, TampilSiswa, uicontroller/Navigasi
- `viewmodel` : SiswaViewModel
